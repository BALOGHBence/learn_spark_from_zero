# Getting Started

- {doc}`Setting Up Databricks Connect <01_setting_up_databricks_connect>`:
  connect your local Python environment to Databricks serverless compute so
  the code examples in this course run as written.
- {doc}`Quizzing Yourself with Claude Code <02_quizzing_yourself_with_claude_code>`:
  use the repository's `certification-quiz` skill to practise with exam-style
  multiple-choice questions, with example prompts.
- {doc}`Taking a Mock Exam with Claude Code <03_taking_a_mock_exam_with_claude_code>`:
  use the repository's `mock-exam` skill to sit a full 45-question practice
  exam that covers every objective, graded only after you submit.
- {doc}`Taking a Mock Exam in the Browser <04_taking_a_mock_exam_in_the_browser>`: run the repository's mock exam app locally to sit the same kind of 45-question exam in a browser, mark questions for review, and export your wrong answers as an LLM prompt or JSON.
