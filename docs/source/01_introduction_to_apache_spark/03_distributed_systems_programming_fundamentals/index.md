# Distributed Systems Programming Fundamentals

The DataFrame API hides most of the machinery of distributed computing, but
not its costs. Code that looks equally simple can be fast or very slow
depending on how much data it moves between machines. This section explains
the mechanics that decide which.

- {doc}`Distributed Systems Programming Fundamentals <03_distributed_systems_programming_fundamentals>`:
  partitions, narrow and wide transformations, shuffles, jobs, stages and
  tasks, join strategies, data skew, Adaptive Query Execution, and fault
  tolerance.
